# Toyota Heater Controller System

## Описание
Система управления нагревателем вентилятора Toyota с Bluetooth-мониторингом согласно ТЗ редакция 6.1 от 01.02.2026.

## Требования к аппаратуре
- Плата: BluePill F103C8T6 (STM32F103C8T6)
- Тактовая частота: 64 МГц (HSI 8 МГц → PLL ×16)
- Память: 64 КБ Flash, 20 КБ RAM
- Загрузчик: STM32duino bootloader (VID:1EAF, PID:0003)

## Распределение выводов
| Пин  | Назначение           | Направление |
|------|----------------------|-------------|
| PA0  | Вход ШИМ вентилятора | Вход        |
| PA2  | Bluetooth TX         | Выход       |
| PA3  | Bluetooth RX         | Вход        |
| PA8  | ШИМ-генератор        | Выход       |
| PB0  | Сигнал «НОРМА»       | Выход       |
| PB1  | ТЭН 1                | Выход       |
| PB10 | ТЭН 2                | Выход       |
| PB11 | ТЭН 3                | Выход       |
| PC13 | Светодиод            | Выход       |

## Компиляция и прошивка
```bash
# Установка зависимостей
pio pkg install

# Сборка проекта
pio run

# Прошивка (BOOT0=0, BOOT1=0)
pio run -t upload

# Мониторинг через UART
pio device monitor
